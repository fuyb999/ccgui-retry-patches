# CC GUI v0.5.2 Canonical Session Title Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish CC GUI `0.5.2-retry.8` with a complete default title taken from the conversation's first real user question, plus complete hover, editing, and persistence behavior.

**Architecture:** Extract a canonical first-user prompt before live-message tail selection and during the full Codex history scan, then transport it as session metadata independent of the bounded visible message list. Store it immutably in the WebView session context, retain explicit manual/AI title precedence, and keep truncation exclusively in CSS.

**Tech Stack:** Java 17, Gson, IntelliJ JCEF bridge, JUnit 4, React 19, TypeScript 5.9, Vitest 3, Node.js CommonJS test runner, LESS, Gradle, Bash, Git unified patches.

**Design:** `docs/superpowers/specs/2026-08-20-ccgui-v0.5.2-canonical-session-title-design.md`

---

- [ ] **Step 3: Implement one complete-prompt extractor**

Expose only these package APIs:

```java
public final class CanonicalSessionTitleExtractor {
    private CanonicalSessionTitleExtractor() {}

    static String fromMessages(List<ClaudeSession.Message> messages) {
        if (messages == null) return null;
        for (ClaudeSession.Message message : messages) {
            String candidate = fromMessage(message);
            if (candidate != null) return candidate;
        }
        return null;
    }

    public static String fromFrontendMessage(JsonObject message) {
        if (message == null || !"user".equals(string(message, "type"))) return null;
        if (isMeta(message) || containsToolResult(message)) return null;
        return normalize(string(message, "content"));
    }
}
```

`fromMessage` must require `Message.Type.USER`, reject `raw.isMeta`, reject
literal `[tool_result]` and any raw `tool_result` content block, remove complete
`agents-instructions`, `system-reminder`, `system-prompt`, and
`local-command-caveat` blocks, reject remaining tag-led/internal-only values,
collapse whitespace to a single space, and return the remaining string without
a length limit. `fromFrontendMessage` applies the same raw-content rules to the
converted history object.
