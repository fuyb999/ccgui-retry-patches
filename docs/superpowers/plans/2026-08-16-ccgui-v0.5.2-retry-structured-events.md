# CC GUI v0.5.2 Retry Structured Events Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish `0.5.2-retry.3`, which shows JSONL-only Codex thinking and tool events within three seconds after retry or compaction while preserving the existing inactivity retry deadline.

**Architecture:** Keep one pending SDK `iterator.next()` guarded by the existing 10-minute inactivity watchdog and race it against cancellable three-second local poll waits. Internal `session.poll` events drive an ordered current-turn JSONL replay for reasoning and tool records; call IDs and reasoning snapshots deduplicate copies later delivered by the SDK.

**Tech Stack:** Node.js ES modules and `node:test`, Codex SDK event stream, JSONL session replay, Java/Gradle IDEA plugin, React/Vitest WebView, Bash patch workflow.

- [ ] **Step 3: Implement cancellable three-second poll races**

Add a constant and a small cancellable timer helper, then keep the watchdog
promise alive across poll ticks:

```js
export const CODEX_SESSION_POLL_INTERVAL_MS = 3_000;

function createSessionPollWait(ms, timers = globalThis) {
  let timer = null;
  const promise = new Promise((resolve) => {
    timer = timers.setTimeout(() => resolve({ kind: 'poll' }), ms);
  });
  return {
    promise,
    cancel() {
      if (timer !== null) timers.clearTimeout(timer);
      timer = null;
    },
  };
}
```

In `withCodexEventInactivityWatchdog`, create the watched `iterator.next()`
once, race it against successive poll waits, yield `{ type: 'session.poll' }`
for poll wins, and replace the watched promise only after a real SDK result.

- [ ] **Step 3: Implement ordered structured replay**

Rename the function-only cursor and replay helpers to structured equivalents.
Extract reasoning summary text from string entries or `{ text }` entries and
dispatch it through `maybeEmitReasoning` with a stable session-line ID before

```js
function extractSessionReasoningText(payload) {
  if (typeof payload?.text === 'string') return payload.text.trim();
  if (!Array.isArray(payload?.summary)) return '';
  return payload.summary
    .map((entry) => typeof entry === 'string' ? entry : entry?.text)
    .filter((entry) => typeof entry === 'string' && entry.trim())
    .join('\n')
    .trim();
}
```

Track `lastReasoningText` in state. For a new stable ID, suppress an identical
last snapshot and treat a prefix extension as a delta continuation; unrelated
text remains a new segment. Handle `session.poll` with the same verified
current-turn replay routine used after real events.
