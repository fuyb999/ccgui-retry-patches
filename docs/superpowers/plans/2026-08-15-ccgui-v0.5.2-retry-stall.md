# CC GUI v0.5.2 Codex Retry And Silent Stream Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible CC GUI `v0.5.2` plugin that carries forward the Codex retry patch, preserves upstream streaming fixes, and never reports a silent attempt as recovered loading.

**Architecture:** Add a version-specific manifest and patch for the exact `v0.5.2` release. Extend the existing retry lifecycle so the bridge reports the initial attempt, IDEA retains scheduled and running states, and the WebView clears running state only when visible data or a terminal event arrives.

**Tech Stack:** Node.js ESM with `node:test`, Java 17 with JUnit, React 18 with TypeScript/Vitest, Bash, Git unified patches, Gradle IntelliJ Platform plugin build.
