# CC GUI v0.5.2 Forked Retry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and track CC GUI `0.5.2-retry.6`, retrying transient Codex failures on disposable threads forked through an immutable last-completed-turn boundary.

**Architecture:** Add a one-request Codex App Server JSON-RPC adapter for `thread/read`, `thread/fork`, and `thread/delete`, while retaining the TypeScript SDK for streamed turns. The message coordinator captures the stable source and completed turn before the first outbound attempt, gates each new retry on cleanup of the failed child, and starts a fresh SDK thread only when there is no completed history to fork.

**Reliability hardening:** Boundary reads mark sources with trailing
non-completed turns so they fork before the nominal first request. Disposable
child IDs remain bridge-local until a complete successful stream is confirmed;
streams ending without `turn.completed` are cleaned and retried. App Server
stderr is drained without retaining or forwarding its content.

**Tech Stack:** Node.js ESM, `@openai/codex-sdk`/CLI `0.148.0`, Codex App Server JSONL RPC, Java 17, JUnit 4, React 18, Vitest, Gradle, Bash, Git unified patches.

**Design:** `docs/superpowers/specs/2026-08-19-ccgui-v0.5.2-forked-retry-design.md`

**Protocol Reference:** <https://learn.chatgpt.com/docs/app-server>

- [ ] **Step 3: Implement one-request JSONL RPC transport**

Keep runtime extraction but replace the CLI event-stream implementation with:

```js
export class CodexAppServerError extends Error {
  constructor(message, details = {}) {
    super(message);
    this.name = 'CodexAppServerError';
    this.code = 'SERVER_ERROR';
    this.details = details;
  }
}

export async function requestCodexAppServer({
  runtime,
  method,
  params,
  signal,
  spawnImpl = defaultSpawn,
}) {
  const connection = createCodexAppServerConnection({
    runtime,
    signal,
    spawnImpl,
  });
  try {
    await connection.request(0, 'initialize', {
      clientInfo: CODEX_APP_SERVER_CLIENT_INFO,
    });
    connection.notify('initialized', {});
    return await connection.request(1, method, params);
  } finally {
    await connection.close();
  }
}
```

The implementation must use newline-delimited objects without a `jsonrpc`
field, wait for response ID `0` before sending `initialized` and request ID
`1`, ignore notifications, and reject duplicate/malformed/mismatched terminal
responses. It must terminate the detached process group on abort and wait for
`close` before returning.

Only a bounded, sanitized stderr suffix may be attached to internal details;
the public error message is method/category only. Do not include params,
prompts, environment values, authorization text, or raw RPC error data.

- [ ] **Step 5: Implement boundary, fork/fresh SDK attempt, and deletion helpers**

Export these APIs:

```js
export async function readCodexStableBoundary({
  runtime,
  sourceThreadId,
  signal,
  requestImpl = requestCodexAppServer,
}) {
  if (!sourceThreadId) {
    return { sourceThreadId: null, lastTurnId: null };
  }
  const result = await requestImpl({
    runtime,
    method: 'thread/read',
    params: { threadId: sourceThreadId, includeTurns: true },
    signal,
  });
  if (result?.thread?.id !== sourceThreadId) {
    throw new CodexAppServerError('Codex thread/read returned a different thread');
  }
  const completed = Array.isArray(result.thread.turns)
    ? result.thread.turns.filter((turn) =>
      turn?.status === 'completed' && typeof turn.id === 'string' && turn.id)
    : [];
  return {
    sourceThreadId,
    lastTurnId: completed.at(-1)?.id ?? null,
  };
}

export async function createCodexRetryAttempt({
  runtime,
  codex,
  threadOptions,
  stableBoundary,
  runInput,
  hasToolActivity,
  signal,
  cleanupSignal,
  requestImpl = requestCodexAppServer,
}) {
  let childThreadId = null;
  let retryThread;
  if (stableBoundary?.lastTurnId) {
    const result = await requestImpl({
      runtime,
      method: 'thread/fork',
      params: {
        threadId: stableBoundary.sourceThreadId,
        lastTurnId: stableBoundary.lastTurnId,
      },
      signal,
    });
    childThreadId = requireDistinctChildId(
      result?.thread?.id,
      stableBoundary.sourceThreadId,
    );
    retryThread = codex.resumeThread(childThreadId, threadOptions);
  } else {
    retryThread = codex.startThread(threadOptions);
  }
  const retryInput = buildCodexForkInput(runInput, hasToolActivity);
  const streamed = await retryThread.runStreamed(retryInput, { signal });
  const events = trackRetryThreadId(streamed.events, (threadId) => {
    childThreadId = threadId;
  });
  return {
    events,
    getThreadId: () => childThreadId,
    cleanup: () => childThreadId
      ? deleteCodexRetryThread({
        runtime,
        threadId: childThreadId,
        signal: cleanupSignal,
        requestImpl,
      })
      : Promise.resolve(),
  };
}

export async function deleteCodexRetryThread({
  runtime,
  threadId,
  signal,
  requestImpl = requestCodexAppServer,
}) {
  try {
    await requestImpl({
      runtime,
      method: 'thread/delete',
      params: { threadId },
      signal,
    });
  } catch (error) {
    if (!isMissingThreadError(error)) throw error;
  }
}
```

For a non-null `lastTurnId`, call `thread/fork`, resume its returned ID with
`codex.resumeThread(childId, threadOptions)`, and run the original input. For a
null boundary, call `codex.startThread(threadOptions)`. Wrap the SDK event
iterable so `thread.started` records the actual fresh ID for cleanup.

`cleanup()` must delete only the child ID and remain retryable after a failed
delete. It becomes permanently idempotent only after deletion succeeds or the
server reports the child is absent.
