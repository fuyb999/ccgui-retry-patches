# CC GUI v0.5.2 Long-Session JCEF Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and track CC GUI `0.5.2-retry.5`, preventing large Codex history replay from exhausting IDEA/JCEF while preserving thinking and tool structure in a tail-only WebView.

**Architecture:** Replace full Codex automatic replay with a streaming bounded frontend window containing the last 180 messages plus one omitted assistant anchor. Allow the first long coalescer snapshot to use the existing indexed tail protocol, and extend the WebView protocol to render a sparse anchor when its full prefix is unavailable. Keep explicit history export and paginated history browsing unchanged.

**Tech Stack:** Java 17, Gson, IntelliJ Platform/JCEF, React 18, TypeScript, Vitest, Gradle, Bash, Git unified patches.

- [ ] **Step 3: Add the bounded streaming collector**

In `HistoryMessageInjector`, add a public helper that reuses
`CodexFrontendMessageAccumulator` without constructing the complete raw JSON
array:

```java
public static List<JsonObject> readRecentCodexFrontendMessages(
        CodexHistoryReader reader,
        String sessionId,
        int tailSize
) throws IOException {
    if (tailSize <= 0) {
        throw new IllegalArgumentException("Codex replay tail size must be positive");
    }

    BoundedFrontendMessageCollector collector =
            new BoundedFrontendMessageCollector(tailSize);
    CodexFrontendMessageAccumulator accumulator =
            new CodexFrontendMessageAccumulator(collector::accept);
    int rawRecordCount = reader.forEachSessionMessage(sessionId, accumulator::accept);
    accumulator.finish();
    List<JsonObject> retained = collector.snapshot();
    LOG.info("[CodexHistoryReplay] codex-bounded-history-window-v1 records="
            + rawRecordCount + ", retainedMessages=" + retained.size()
            + ", tailSize=" + tailSize);
    return retained;
}

private static final class BoundedFrontendMessageCollector {
    private final int tailSize;
    private final Deque<JsonObject> tail = new ArrayDeque<>();
    private JsonObject latestAssistant;

    private BoundedFrontendMessageCollector(int tailSize) {
        this.tailSize = tailSize;
    }

    private void accept(JsonObject message) {
        if ("assistant".equals(getStringProperty(message, "type"))) {
            latestAssistant = message;
        }
        tail.addLast(message);
        if (tail.size() > tailSize) {
            tail.removeFirst();
        }
    }

    private List<JsonObject> snapshot() {
        List<JsonObject> result = new ArrayList<>(tail.size() + 1);
        boolean assistantInTail = false;
        for (JsonObject message : tail) {
            if (message == latestAssistant) {
                assistantInTail = true;
                break;
            }
        }
        if (latestAssistant != null && !assistantInTail) {
            result.add(latestAssistant);
        }
        result.addAll(tail);
        return result;
    }
}
```
